# 声桥 iPhone App：在 Mac 上用 Xcode 装到手机

需要：一台 Mac（装好 Xcode）、iPhone（iOS 16 或更新）、一根数据线、一个 Apple ID（免费的就行）。

## 安装步骤

1. **打开工程**：双击 `ios/ShengQiao.xcodeproj`，Xcode 会打开它。
2. **选签名团队**：左边点最上面的蓝色“ShengQiao”→ 中间选 TARGETS 下的“ShengQiao”→“Signing & Capabilities”。
   - 勾上“Automatically manage signing”。
   - Team 选你的 Apple ID（显示为“你的名字 (Personal Team)”）。没有的话点“Add an Account…”登录。
   - 如果提示 Bundle Identifier 被占用，把 `com.shengqiao.app.x7k2` 改成别的，比如末尾换几个字母。
3. **连手机**：用数据线连 iPhone，手机上点“信任此电脑”。
   第一次用要在 iPhone 上打开 设置 → 隐私与安全性 → **开发者模式**（打开后手机会重启）。
4. **运行**：Xcode 顶部中间选你的 iPhone 作为目标设备，点左上角的 ▶︎（或按 ⌘R）。
5. **信任开发者**：第一次装好后，手机上打开 设置 → 通用 → VPN与设备管理 → 点你的 Apple ID → 信任。
   然后在桌面上打开“声桥”。

用免费 Apple ID 签名的 App **7 天后会打不开**，到时候连上数据线在 Xcode 里再点一次 ▶︎ 就续上了（设置和配对都还在）。
付费开发者账号签名可以用一年。

## 第一次打开

- 允许“查找本地网络上的设备”：App 才能自动找到电脑。
- 点“当麦克风”时允许使用麦克风；点“扫码连接”时允许使用相机。
- 电脑上要先运行声桥，手机和电脑连同一个 Wi-Fi。App 会自动发现电脑，第一次连接输入电脑上显示的访问码，
  或者直接扫电脑上的二维码。

## USB 数据线连接

不想用 Wi-Fi 时：用数据线把 iPhone 接到电脑，**保持声桥 App 在前台**，电脑上的声桥会自动连过来（顶部显示“电脑名 · USB”）。
手机上第一次要点“信任此电脑”；电脑需要装 iTunes 或微软商店的“Apple 设备”App。
USB 和 Wi-Fi 同时可用时优先走 USB，拔线后自动回到 Wi-Fi。在“连接电脑”页可以关掉“USB 直连”。

## 用法

- **听电脑**：电脑的声音从手机出来，锁屏或切到别的 App 也会继续播放。延迟档位：低 / 均衡 / 稳。
- **当麦克风**：手机麦克风的声音传到电脑的 VB-CABLE，电脑上的软件选 **CABLE Output** 当麦克风。
  锁屏后也能继续（状态栏会显示橙色麦克风标志）。
- 两个可以同时开。用手机外放时打开“消除回声”；戴耳机可以关掉，音质更好。
- **降噪**（关闭 / 轻度 / RNNoise / 强力）在电脑端处理，在 App 的麦克风区域选择，和“消除回声”互相独立。

## 编译报错怎么办

把 Xcode 左边“问题导航”（⚠︎ 图标）里的红色错误截图发给帮你部署的人。
`tools/gen_xcodeproj.py` 可以重新生成工程文件（加了新的源文件后用）。
