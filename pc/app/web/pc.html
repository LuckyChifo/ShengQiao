帮助与日志

怎么用 USB 连接？
  1. 安卓：插入数据线，在手机设置里开启「USB 网络共享」，无需 USB 调试。在设备页点「刷新检测」，再查看 USB 共享地址，在手机 App 中填写 IP、端口和访问码。部分手机的设置入口叫「个人热点」或「连接与共享」。
  2. 直连（推荐）：数据线接好 iPhone，打开声桥 App，电脑上会自动连上，不用 Wi-Fi、不用开个人热点。电脑需要装 iTunes 或微软商店的“Apple 设备”App（里面带 Apple Mobile Device Service），手机上第一次要点“信任此电脑”。
  3. USB 共享网络：不想装 iTunes 的话，在 iPhone 上打开“个人热点”再插线，电脑会多出一张“Apple Mobile Device Ethernet”网卡。控制页会自动认出它，用 USB 卡片里的地址扫码或在 App 里手动输入即可。
  4. 连不上：确认手机已解锁、App 开在前台；换一根能传数据的线；在电脑上看“Apple Mobile Device Service”服务是否在运行。
手机连不上？
  1. 防火墙：首次运行时 Windows 会问要不要允许访问，两个网络类型都勾上点“允许”。错过了就运行文件夹里的 firewall.bat。
  2. App 里看不到电脑：首次打开 App 时要允许“查找本地网络上的设备”；也可以直接扫码连接。
  3. 同一个网络：手机要连电脑所在的 Wi-Fi，不能用流量。校园网、酒店 Wi-Fi 常常禁止设备互访，这时让电脑连手机的个人热点就行。
  4. 代理/VPN：Clash 等软件的 TUN 模式偶尔会挡住局域网访问，可暂时关掉试试。
  5. 电脑不想出声：有些声卡静音或调小电脑音量后，手机也会跟着没声或变小（手机端音量可拉到 200% 补回）。注意：VB-CABLE 用来当麦克风时，不要把它设成 Windows 默认输出，否则电脑的声音会混进麦克风。
  6. 用蓝牙耳机：AirPods 等蓝牙耳机本身有 0.15–0.25 秒延迟，看视频对不上口型属正常。
