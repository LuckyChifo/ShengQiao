# 声桥（电脑端）：电脑声音 ⇄ iPhone

- **听电脑**：电脑正在播放的声音（视频、音乐、游戏、网课）实时从 iPhone 里放出来。
- **当麦克风**：iPhone 的麦克风变成电脑的麦克风（通过 VB-CABLE），QQ、微信、腾讯会议、OBS 都能用。

手机端可用“声桥”App（收听、麦克风都有）；没装 App 的话也可以用 Safari 或 Chrome 扫码收听（只能听，不能当麦克风）。网页的实时播放与锁屏收听使用同一链路，无需选择单独的锁屏模式。
只支持 Windows 10 / 11。

## 第一次使用

1. 把整个文件夹解压到一个固定的位置（例如 `D:\声桥`），别直接在压缩包里运行。
2. 双击 `start.bat`。
   - 第一次会自动下载官方便携版 Python（约 11 MB，只下这一次，不装进系统），并在桌面和开始菜单建一个“声桥”图标。
   - 如果 Windows 提示“已保护你的电脑”，点“更多信息”→“仍要运行”。
3. 如果弹出 Windows 防火墙提示：**“专用网络”和“公用网络”都勾上**，点“允许访问”。
4. 浏览器会打开声桥控制页，上面有二维码。右下角托盘区会出现声桥图标。

以后直接点桌面上的“声桥”图标启动。关闭方法：右键托盘图标 →“退出声桥”。
托盘菜单里可以打开“开机时自动启动”。

## 用数据线连接（USB）

- **安卓 USB 网络共享**：用支持数据传输的线连接电脑，在手机「设置 → 个人热点／网络共享」中开启「USB 网络共享」，再打开声桥 App。无需开启 USB 调试，也不用安装 iTunes。
  在电脑「设备」页点「刷新检测」，然后点「查看 USB 共享地址」。在安卓 App 中选择发现的电脑，或手动填写该地址的 IP、端口和访问码。
  常见 RNDIS、USB NCM 共享网卡会自动识别，连接后显示「USB 共享」。若系统使用了未识别的驱动，可在首页「切换地址」中选择该网卡的 IP，手动连接。
- **直连**：用数据线接好 iPhone，打开手机上的声桥 App（保持在前台），电脑上的声桥会自动连上，不用 Wi-Fi 也不用开个人热点。
  需要电脑装有 iTunes 或微软商店的“Apple 设备”App（里面带 Apple Mobile Device Service），手机上第一次要点“信任此电脑”。
- **USB 共享网络**：不想装 iTunes 的话，在 iPhone 上打开“个人热点”再插线，电脑会多出一张 Apple Mobile Device Ethernet 网卡。
  声桥控制页的“USB 连接”卡片会给出这张网卡上的地址，点“用 USB 共享地址生成二维码”后用 App 扫码即可。
- 「设备」页的「USB 连接」卡片分别提供安卓与 iPhone 的操作说明；开启共享后可点击「刷新检测」立即更新。

## 手机当麦克风（需要 VB-CABLE）

1. 安装 VB-CABLE（免费，vb-audio.com），装完重启一次电脑。
2. 在 iPhone 的声桥 App 里打开“当麦克风”。
3. 在要用麦克风的软件里，把麦克风选成 **CABLE Output (VB-Audio Virtual Cable)**。

### 降噪和回声消除

- **降噪**在电脑端处理，App 和电脑控制页里都能选，两边会同步：
  - **关闭**：最原始的声音。
  - **轻度**（频谱减法）：压风扇、空调这类持续的噪声，几乎不伤人声；对键盘声这种突发噪声无效。多 10 毫秒延迟。
  - **RNNoise**（默认，推荐）：xiph.org 的神经网络降噪，键盘、杂音也能压掉。多 20 毫秒延迟；开麦后前 0.2 秒是静音（模型预热）。
  - **强力**：RNNoise 加噪声门，不说话 0.2 秒后自动静音，适合很吵的环境。
- **回声消除**在 iPhone 上处理（App 里的“消除回声”开关，用的是 iOS 系统的语音处理），和降噪互相独立。
  用手机外放听电脑声音、同时又开着麦克风时要打开；戴耳机可以关掉，音质更好。
  它只能消掉手机自己放出来的声音：如果电脑音箱也在外放，手机又离得近，那部分消不掉，让电脑静音或戴耳机。

注意：
- **不要**把 CABLE Input 设成 Windows 的默认输出（播放）设备，否则电脑的声音会混进麦克风，手机也听不到正常的电脑声音。
- 用手机外放听电脑声音、同时又开着麦克风时，App 里的“消除回声”要打开；戴耳机可以关掉，音质更好。

## 自检（遇到问题先跑这个）

双击文件夹里的 `selftest.bat`。它会检查 VB-CABLE、麦克风链路（声音能不能从声桥写进 CABLE Input、再从 CABLE Output 录回来）、电脑声音采集（会听到 1.5 秒小声的“嘟”）和网络，结果保存在 `selftest.txt`。把这个文件发给帮你部署的人就能定位问题。

想看程序运行时的全部输出：双击 `debug.bat`（在命令行窗口里运行，不显示托盘图标）。

## 常见问题

**App 里看不到电脑 / 手机打不开网页**
- 防火墙：运行文件夹里的 `firewall.bat`（会请求管理员权限），它会放行声桥。
- 不在同一个网络：手机要连电脑所在的 Wi-Fi，不能用流量。校园网、酒店、公司 Wi-Fi 经常禁止设备互相访问，
  这时让**电脑连 iPhone 的个人热点**就可以。
- iPhone 第一次打开 App 时要允许“查找本地网络上的设备”。不允许的话，也可以在 App 里扫码连接。
- 代理软件：Clash 等的 TUN 模式有时会挡住局域网访问，暂时关掉试试。

**能连上但手机听不到声音**
- 看控制页上“采集”的电平条：电脑放音乐时它应该会动。不动就检查采集设备选得对不对。
- 有些声卡静音或调小电脑音量后，传到手机的声音也会跟着没了或变小（手机端音量可以拉到 200% 补回来）。

**电脑那边听不到我（麦克风）**
- 控制页“手机当麦克风”一栏要显示“正在接收手机麦克风 → CABLE Input”。
- 软件里的麦克风要选 CABLE Output，不是 CABLE Input。
- 双击 `selftest.bat`，看第 2 部分。

**偶尔卡一下**：App 里延迟选“稳”；手机靠近路由器，或者连 5 GHz 的 Wi-Fi。

**口型对不上**：如果 iPhone 连的是 AirPods 等蓝牙耳机，耳机本身就有 0.15–0.25 秒延迟，用手机外放或有线耳机会好很多。

**访问码是什么**：防止同一个 Wi-Fi 下的其他人偷听你的电脑或冒充你的麦克风。扫码时已经带上了；
App 配对过一次就会记住。首页「连接手机 → 设置访问码」可手动设置 4–16 位英文字母或数字，也可以点击「随机生成新码」。访问码不区分大小写，保存后立即生效，并在重启后保留；二维码和连接链接会同步更新，已连接的网络设备需使用新码重新连接。
「刷新连接信息」只重新读取地址和 USB 共享网卡、刷新二维码，不更改访问码。

## 文件说明

- `start.bat`：第一次运行用；之后用桌面上的“声桥”图标
- `selftest.bat`：自检；`debug.bat`：带运行日志的窗口模式
- `firewall.bat`：放行防火墙（需要管理员）
- `app/`：程序本体（Python 服务端 + 网页）
- `deps/`：依赖库
- `runtime/`：第一次运行时自动下载的便携 Python
- `config.json`、`log.txt`：设置和日志（运行后生成）

卸载：右键托盘图标退出，关掉“开机时自动启动”，删掉整个文件夹和桌面图标。
如果运行过 `firewall.bat`，可以在“Windows Defender 防火墙 → 高级设置 → 入站规则”里删除名字带 ShengQiao 的规则。
